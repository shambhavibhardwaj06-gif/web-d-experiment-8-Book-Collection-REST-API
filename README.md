# Book Collection RESTful API

## Project Description
This project is a RESTful API developed using Node.js and Express.js to manage a collection of books.

## Features
- Add a new book
- View all books
- View a book by ID
- Update book details
- Delete a book

## Technologies Used
- Node.js
- Express.js
- JavaScript
- Visual Studio Code

## Installation

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
npm start
```

Server runs at: `http://localhost:3000`

## API Endpoints

| Method | Endpoint | Operation |
|---|---|---|
| POST | /books | Add a book |
| GET | /books | Get all books |
| GET | /books/:id | Get a book by ID |
| PUT | /books/:id | Update a book |
| DELETE | /books/:id | Delete a book |

Successfully developed a Book Collection RESTful API with CRUD operations using Node.js and Express.js.
